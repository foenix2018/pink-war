## Canon prioritaire fixé par le créateur

- Deux héros égaux, **GHJU (fille de petite taille, blonde aux yeux bleus)** et **LYLU (garçon)**, frère et sœur ; le jeu rend hommage à leur lien familial. Ils **conservent leurs designs, équipements et modèles Shadow Unit réels** déjà présents dans le jeu. GHJU rose, LYLU bleu. Ne pas substituer des modèles illustrés à ceux de la production.
- **Gaby** : sphère rose gravitant autour de GHJU, bouclier et soin, soutien réfléchi dans les dilemmes moraux.
- **Cara** : sphère bleue gravitant autour de LYLU, attaques et amplification des dégâts ; ton familier/provocateur, analyses pertinentes.
- **Univers :** 50 % cyberpunk et 50 % science-fiction militaire ; ton adulte/sombre. **Vesper** est une ville humaine ; **ORDRE** une IA ennemie ; **Nharis** l'autre monde.
- **Final :** sacrifice choisi entre GHJU et LYLU. Le volontaire doit rester de l'autre côté pour maintenir la Fracture close, accompagné de son IA. La fin est **ouverte** : aucun décès ni sauvetage confirmé. Les deux branches ont une valeur narrative égale.
- **Vie privée :** n'inscrire dans la documentation publique que les noms fictifs des personnages, pas les prénoms réels auxquels ils rendent hommage.

## Différence entre l'existant et le futur

Les documents précisent « existant / vérifié dans le dépôt » ou « cible / proposé ». Lorsque l'ancienne bible `docs/LORE.md` contredit cette conception — notamment son ancienne règle « aucune IA alliée », ou son ancien dénouement — **le nouveau canon prévaut uniquement pour la conception future**. Ne pas supprimer ni modifier rétroactivement le jeu existant sans plan de migration.

## Démarrage d'une tâche Codex

> Lis les quatre documents de `docs/pink-wars/` et les fichiers historiques cités ci-dessus. Analyse le code réel actuel, compare-le au canon, établis une matrice « existant / absent / à adapter », puis propose une feuille de route découpée en livraisons testables. Ne change pas le code, les modèles, les commandes, la production Vercel ni les assets tant que je ne t'ai pas demandé une implémentation précise.

**Important :** les planches d'illustration et les maquettes produites hors du dépôt sont des concepts de référence ; leurs visages, proportions ou armures ne constituent pas une preuve du modèle réel. Les visualiseurs du jeu restent la référence de chara-design.
