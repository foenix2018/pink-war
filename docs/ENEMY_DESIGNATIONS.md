Les noms de fonctions, d'imports, les clés de sauvegarde, les identifiants de formes et les références de version de modèles historiques (RECO1, BRUTE_V3, etc.) restent inchangés, afin de préserver les logiques de jeu, les effets et le squelette des ennemis. Les matricules ci-dessus sont leurs noms d'affichage dans la galerie, les scènes et les dialogues. Les inscriptions déjà intégrées dans les anciennes images ou illustrations ne sont pas réécrites automatiquement.

Pour le Spectre SP-09 : le concept sniper est référencé mais ne devient pas un ennemi opérationnel ni un faux modèle 3D avant son intégration et ses tests.
